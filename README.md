# Spotify Island — retired

The custom plugin and standalone runtime have been retired in favor of Noctalia's built-in media controls and Spotify's native tray integration.

The current setup is machine configuration in [masonjacob/nix-config](https://github.com/masonjacob/nix-config), under `modules/home-manager/programs/spotify/` and its Hyprland desktop module.

This repository no longer contains an installer, plugin or playback service. Earlier code remains in Git history for reference.
